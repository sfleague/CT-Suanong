🔥 Cloud Storage — Firebase

เชื่อมต่อข้อมูลกลาง ใช้ได้ทุกเครื่อง · ข้อมูลเก่า 7 วันลบอัตโนมัติ
วิธีตั้งค่าครั้งแรก (ฟรี ไม่มีค่าใช้จ่าย):
  1. ไปที่ console.firebase.google.com → สร้าง Project ใหม่
  2. เลือก Realtime Database → สร้าง database (เลือก mode: test หรือ locked)
  3. copy Database URL เช่น https://project-id-default-rtdb.firebaseio.com
  4. ไปที่ Project Settings → Service accounts → Database secrets → สร้างและ copy Secret
  5. วาง URL และ Secret ด้านล่าง แล้วกด เชื่อมต่อ 🔥
เก็บใน localStorage ของเครื่องนี้เท่านั้น · ข้อมูลพัสดุเก่ากว่า 7 วันจะถูกลบอัตโนมัติ
